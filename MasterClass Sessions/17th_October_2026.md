## What is IBM Bob?

**IBM Bob** (`bob.ibm.com`) is IBM's AI-powered coding agent — like having VS Code with a built-in AI that can:

- Generate complete project files from a single prompt
- Auto-create README files
- Write requirement files
- Build project reports
- Integrate with your existing editor (VS Code, Cursor, Windsurf)

> ⚠️ IBM Bob is **not free** — but offers a **30-day free trial**. Download is mandatory to get the VS Code extension.

### IBM Bob vs Other AI Tools

| Tool | Cost | Recommendation |
|---|---|---|
| **IBM Bob** | Paid (30-day free trial) | **Recommended** — gives README, requirements, project report auto-generated |
| GitHub Copilot | Paid | Alternative — but you'd need to manually create report/readme |
| Claude | Free + Paid tiers | Good for generating prompts to feed into IBM Bob |
| ChatGPT | Free + Paid tiers | Good for brainstorming topics and prompts |
| Antigravity | Free (limited) | Some students asked about it — Himanshu said IBM Bob is "easier" |

> 💡 **Workflow Tip from Harshit Bisht:** Use Perplexity or GPT to understand IBM Bob's free plan, then craft a smart prompt about your low-budget condition, and feed that to Bob.

### What Goes in a README?

> *"README is a summary of your project. It explains what the project does, how to run it, and any other relevant info."* — Harshit Bisht

A typical README contains:
- Project title and description
- Features
- Installation steps
- Usage instructions
- Technologies used
- Author info

## IBM Bob Setup — Step by Step

### Step 1: Download IBM Bob

1. Go to **https://bob.ibm.com/download**
2. Download the installer for your OS
3. Run the installer

### Step 2: Login / Sign Up

- Click **Sign Up with Google** (recommended)
- If you already have an IBM account, click **"I already have an IBM account"**
- ⚠️ If your free trial is finished: try logging in with **another Google account**

### Step 3: Editor Integration

During setup, IBM Bob asks which editor to import settings from:

| Editor | When to Choose |
|---|---|
| **VS Code** | If you use VS Code (most popular choice) |
| **Cursor** | If you use Cursor |
| **Windsurf** | If you use Windsurf |

> *"Whichever you use. I use VS Code, so I imported settings from there."* — Pawan Murali

### Step 4: How to Use

1. Open IBM Bob
2. Start a new project / file
3. **Type a prompt** describing what you want to build
4. Bob generates the code, README, requirements file, and project report automatically
5. Edit / refine the generated code as needed
6. Save and push to GitHub

> 💡 **Tip:** Be detailed in your prompt. Tell Bob exactly how you want your website to look and what content it should have. Then it generates everything for you.

## Project Submission Process

| Step | Action |
|---|---|
| 1 | Build the project using IBM Bob (or your preferred AI tool) |
| 2 | Test the code locally |
| 3 | Create a README file (auto-generated by Bob, edit if needed) |
| 4 | Create a Project Report file (auto-generated by Bob) |
| 5 | Create a Requirements file (auto-generated by Bob — lists dependencies) |
| 6 | Push everything to a **GitHub repository** |
| 7 | Wait for the **submission Google Form** (will be shared soon) |
| 8 | Submit the GitHub repo link + required files via the form |

### If You Have Multiple Code Files

> *"If we have so many files for code, how to send in form?"* — Rahul Melkani

**Answer:** Compress into a **ZIP file** and upload, or push to GitHub and share the repo link.

### If You're Using API Keys

> *"What if we use any API keys then how to submit the project on GitHub?"* — ramizali saiyed

**Answer:** Don't commit your API keys directly! Use a `.env` file, add it to `.gitignore`, and document the placeholder in your README.

## Workflow Recommendation (Based on Chat Discussions)

For students unsure how to start, here's the recommended flow:

```
Step 1: Pick a cybersecurity topic that interests you
        (e.g., phishing detector, password strength checker, port scanner)

Step 2: Use ChatGPT/Claude to brainstorm the project scope
        (What features? What tech stack? What's the user flow?)

Step 3: Open IBM Bob, write a detailed prompt describing the project
        (Be specific about features, UI, tech stack, output format)

Step 4: Bob generates:
        - Source code
        - README file
        - Requirements file
        - Project report

Step 5: Review the generated code, edit if needed
        (Use Claude or other AI tools to refine specific parts)

Step 6: Test the project locally on your PC

Step 7: Push everything to a GitHub repository
        (Use .gitignore for API keys!)

Step 8: Wait for the submission form → submit:
        - GitHub repo link
        - Code file
        - Requirement file
        - Project report file
        - README

Step 9: Done! 🎉
```
